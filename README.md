# Прогнозирование выработки Азовской ВЭС
*от команды train_twins*

Хакатон «Прогнозирование производства электроэнергии ВЭС»

Решение основано на ансамбле из 11 моделей CatBoost с Ridge-стекингом, дополненном глубокой физической проработкой признаков.  
Достигнутая метрика на Q1 2026: **7.987%** (MAE относительно установленной мощности 90.09 МВт).

## Быстрый старт
1. Установите зависимости: `pip install -r requirements.txt`
2. Поместите обучающие данные в `data/`:
   - `train_dataset.csv`
   - `valid_features.csv`
   - `april_may_data.csv` (для 18 мая)
3. Прогноз на Q1: `python pipelines/generate_submission_q1.py`
   Результат: `outputs/submission_q1.csv`
4. Прогноз на 18 мая: `python pipelines/generate_submission_may18.py`
   Результат: `outputs/submission_may18.csv`

## Архитектура модели
- Физические признаки: интерполяция на 84 м, плотность воздуха, V³, порывы, вертикальный сдвиг, стабильность, локальные эффекты Азовской ВЭС (бриз, обледенение, восточные штормы).
- Временные признаки: лаги, лиды, скользящие статистики.
- Ансамбль: 3 базовые + 5 прямых + 3 на остатках (Residual), объединённые Ridge‑регрессией и изотонической калибровкой.
- Кросс‑валидация: TimeSeriesSplit с разрывом.

## Воспроизводимость
- Все seed зафиксированы (42).
- Параметры моделей зашиты в коде.
- Запуск детерминирован.

## Структура
- `features/` – генерация признаков
- `models/` – обучение и инференс
- `pipelines/` – точки входа
- `data/` – исходные данные (не включены в репозиторий)
- `outputs/` – результаты
