# Пояснительная записка

## Команда: Train_Twins

## Задача
Прогнозирование почасовой выработки Азовской ВЭС (90.09 МВт, 26 турбин Vestas V126-3.45) на основе метеопрогнозов Open-Meteo.

## Описание модели

### Признаки (73 шт.)
- **Физические**: интерполяция скорости ветра на высоту оси ротора (84 м), плотность воздуха, V³, коэффициент мощности, вертикальный сдвиг ветра, турбулентность, порывы.
- **Географические**: прокси морского бриза (Азовское море), направление ветра с моря, обледенение, восточные штормы.
- **Временные**: лаги (1–6 ч), лиды (1–3 ч), скользящие статистики (12/24 ч), ускорение ветра, градиент давления, взаимодействие месяц×час.
- **Unsupervised**: KMeans-кластеры ветрового режима (5 кластеров) + расстояния до центроидов.

### Архитектура ансамбля (11 моделей CatBoost GPU)
1. **Baseline** (3 модели) — предсказание capacity factor напрямую.
2. **Direct** (5 моделей) — аналогично, с вариацией гиперпараметров.
3. **Residual** (3 модели) — предсказание остатков (CF_actual − CF_physics).

Предсказания объединяются:
- Ridge-регрессия (α=0.5, positive=True) по 4 входам: physics_cf, direct_pred, residual_pred, sum.
- Изотоническая калибровка.
- Оптимальный бленд baseline vs stack (подбор на OOF).

### Кросс-валидация
TimeSeriesSplit (5 фолдов) с разрывом 24 часа для предотвращения утечки.

### Результат
- OOF MAE%: ~8.0% (относительно установленной мощности 90.09 МВт)
- Лидерборд Q1 2026: **7.987%**

## Инструкция по запуску

### Требования
```
pip install catboost pandas numpy scikit-learn scipy joblib
```
Необходима GPU с поддержкой CUDA (CatBoost GPU). Если GPU нет — установите переменную: `set CATBOOST_CPU=1`.

### Данные
Поместите в папку `data/`:
- `train_dataset.csv` — обучающая выборка
- `valid_features.csv` — тестовые метеоданные Q1
- `april_may_data.csv` — данные апрель-май (для прогноза 18 мая)

### Запуск
```bash
# Прогноз Q1 2026
python pipelines/generate_submission_q1.py
# Результат: outputs/submission_q1.csv

# Прогноз 18 мая 2026
python pipelines/generate_submission_may18.py
# Результат: outputs/submission_may18.csv
```

### Воспроизводимость
Все random seed зафиксированы (42). Результат детерминирован при одинаковом оборудовании.
